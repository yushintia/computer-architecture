1. **B** — a bit is one single 0 or 1, the smallest piece of information a computer stores
2. **B** — `1110` (8 + 4 + 2 + 0 = 14)
3. **B** — hex is only a shorter, easier way to write the same bits, one hex digit per 4 bits
4. **B** — invert every bit, then add 1, is the two's complement trick for writing a negative number
5. **B** — overflow happens when a result needs more bits than it has, and silently wraps to a wrong number
6. **B** — ASCII assigns every text character an agreed-on number, so machines agree on what a letter means
7. Unsigned: 254. Signed: flip `00000001` and add 1 gives 2, so the pattern is -2
8. **Model answer:** "The bits themselves carry no label. The same pattern can be read using the unsigned rule, where every bit only adds a positive amount, or the signed two's complement rule, where the pattern can represent a negative number instead."
